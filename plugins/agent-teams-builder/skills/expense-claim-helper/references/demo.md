# 請款格式範例（去識別共用版）

本檔說明資料類型與 ERP 固定選項，不保留原影片的人名、員工／部門代碼、銀行資料、實單號碼或影片名稱。以下值不能直接送入實際請款；代碼須由使用者提供並核對。若使用者要求沿用原影片資料，請使用者提供原始資料，共用包無法還原。

| 欄位 | 格式與來源 |
|---|---|
| 公司 | 使用者已確認的公司全名 |
| 單別 | 使用者已確認的單別；原流程校準一般費用請款單（員工） |
| 單號 | ERP 自動編列，不手填或沿用歷史號碼 |
| 單據日期／請款日期 | 本次明確指定的 YYYY-MM-DD |
| 申請人／對象代碼 | 本次申請人／對象，名稱由 ERP 帶出 |
| 部門／費用部門 | 已核對的部門代碼 |
| 廠別 | 已確認的廠別 |
| 幣別／匯率 | 本流程僅支援 NTD／1，仍須明確提供 |
| 支領方式／異動對象 | 已校準固定選項 2.轉帳／1.人員 |
| 銀行行號／帳號 | 本次明確提供的文字值，保留前導零 |
| 付款條件 | 本次明確提供的值或空字串 |
| 預計付款日／兌現日 | 本次日期；允許留空者需明確空字串 |
| 表頭備註／憑證張數 | 本次備註及張數 |
| 明細筆數 | 僅一筆 |
| 費用代號／專案 | 本次已核對的代碼，不使用歷史範例代碼 |
| 摘要／金額 | 本次用途與金額 |
| 費用名稱／會計科目／合計 | ERP 輸出，核對實際畫面 |
| 憑證類別／收據號碼 | 3.收據／明確空字串；有號碼收據尚未校準 |

來源文件記載 2026-09-10 在原 Windows 環境完成一筆新增、單次儲存、取消自動下一張空白單、精確查回及模型核對。本次共用封裝只做離線驗證，不把這段歷史描述當作新設備實測證據。
