# 請款小幫手

在 Cosmos ERP iGP 完成一般費用請款建立作業。此流程已於 2026-09-10 在 PCMI10 iGP2.0 (16.0.2.1) 實際完成新增、儲存及查回核對。

## 本次資料與執行範圍

以當次使用者提供的資料、影片及既有對話授權為準。先辨明是新增、修改既有單，還是只填寫供核對。使用者已要求完成並儲存時，接續完成，不重複詢問儲存許可；只要求預填時，停在儲存前。建立技能本身不代表要再新增一張單。

新請款使用本次申請人、日期、部門、付款資料、摘要、金額及專案，不將歷史示範值當預設。缺少必要資料且 ERP 無可核對的合理帶入值時，提出精簡問題並繼續不依賴答案的工作。僅在使用者明確要求沿用原示範資料時，讀取 [references/demo.md](demo.md)。

## 連接與辨識畫面

1. 使用當前環境的 Windows Computer Use 工具；先讀已安裝的 computer-use 技能及其操作文件。已驗證環境使用 Node REPL 匯入 `@oai/sky`。工具名稱與安裝路徑可能隨設備改變，先探索可用工具。
2. 用 `list_windows` 找 Cosmos ERP iGP 或已開啟的 PCMI10。從工具回傳物件取得視窗、啟用並擷取當前畫面。未開啟時從實際發現的 ERP 應用程式啟動，勿套用舊電腦路徑、PID、HWND。
3. 從「作業清單」→「零用金管理系統」→「一般費用請款建立作業」進入 **PCMI10**。若已在正確作業，直接接續。先核對公司、作業名稱、狀態及是否有未儲存資料。
4. 畫面不完整、明細不可見、對話窗無法控制時讀 [references/window-recovery.md](window-recovery.md)。截圖可見不等於能操作；登入由使用者完成。

## 新增表頭與付款資料

1. 按左上方紙張綠色加號 **「新增」**，確認下方狀態為「新增」。查詢用於讀取單據，不能取代新增。
2. 輸入本次單別。已驗證員工一般費用請款為 **I502**，首字是大寫英文字母 I；離開欄位核對「一般費用請款單（員工）」。新單號由 ERP 編列，空白單號欄離開後會產生；記錄號碼，不複製影片或既有單號。
3. 核對單據日期、請款日期，輸入申請人並離開欄位，檢查姓名及自動帶出的部門。核對廠別、幣別與匯率。
4. 選擇本次支領方式及異動對象，再填對象代碼並核對姓名。此版本新增預設為「3.支票」「2.廠商」；員工轉帳示範使用「2.轉帳」「1.人員」。勿漏改預設。
5. 按資料填銀行行號、銀行帳號、付款條件。付款條件離開欄位後會重算預計付款日與兌現日，因此最後核對並設定所需日期。
6. 日期欄位是遮罩輸入：可從第一個數字點選後輸入八位 `YYYYMMDD`，檢查顯示 `YYYY/MM/DD`。曾驗證 `set_value` 失敗，不將 UIA 編輯索引當固定欄位映射。付款日離開後可能同步更新兌現日，仍需核對兩者。
7. 填表頭備註及本次憑證張數。保留與本次請款相符的 ERP 流程設定；本技能不自行更改公司簽核設定。

## 新增費用明細

1. 明細表看不到時拖曳「費用資料」底部與明細間分隔線，展開欄位。點第一個空白明細列可新增一列，核對自動帶入的費用部門與請款人。
2. 填費用代號，離開欄位檢查費用名稱及自動會計科目；不要把示範的科目強行覆蓋到不同費用。
3. 輸入摘要，核對報銷來源。依畫面用 Tab 或水平捲動移至後續欄位，每次確認焦點，不盲目批次送出多個 Tab。
4. 輸入原幣金額，離開欄位核對本幣、未稅金額、稅額。按本次憑證選類別；示範是「3.收據」，不同於新增預設「1.統一發票」。
5. 填本次需要的收據號碼、明細備註、專案等欄位。專案代碼需核對大小寫與回傳名稱，已驗證 **ZZ → 全品牌**；小寫 zz 曾報不存在，不重演錯誤。
6. 多列時依本次資料逐列新增。離開明細列後，ERP 才會更新單身筆數與合計。核對列數、原幣與本幣應付金額及稅額。

## 儲存與成功判定

1. 核對單別、系統單號、日期、申請人、付款對象、銀行資料、付款日期、備註、各列金額與專案。若存在欄位錯誤，修正後再保存。
2. 在本次授權範圍內按 **「儲存」** 一次。等待並重新讀取畫面；出現驗證錯誤時依內容處理，不能當作成功。
3. 此版本儲存後會自動進入下一張空白新增單，號碼遞增。先確認這是新空白單，再用「取消」離開該空白表單。
4. 用「查詢」按原單別及剛儲存的確切單號查回。核對處於「瀏覽」、單號一致、明細筆數、摘要、金額、憑證、專案及付款資料。成功查回才回報完成。
5. 若儲存結果不明，先查原單號；未查清前勿再次新增或反覆按儲存，避免重複單。若無法核實，清楚回報已做動作與尚未確認的結果。
6. 完成後留在已儲存單據的瀏覽畫面，回報單別／單號、內容、金額及查回結果。按需要保存本地核對畫面，不將含公司資料的截圖打包進共用技能。

## 操作節奏

每次依最新畫面或可讀 UIA 定位；輸入前確認焦點，動作後讀回。截圖座標、欄位索引、視窗識別碼不可跨回合或設備硬編碼。對話窗需單獨定位，不能對主視窗送文字猜測焦點。使用者手動切換畫面後先重新觀察。
