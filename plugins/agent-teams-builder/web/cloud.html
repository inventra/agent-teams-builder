返回 VIXO

登入這台裝置

輸入你在 VIXO 設定的帳號密碼，即可取得原本的雲端內容。

已有 Agent 的舊裝置：請回到已連線、保有原本 Agent 的 VIXO 裝置，在本頁選擇「設定帳號密碼」。完成後，網站和其他裝置即可直接登入同一份內容。

新同仁：註冊帳號

建立帳號後，需等 Kevin 管理員核准才能使用雲端。核准不會自動加入團隊或取得其他人的私人資料。

已有 Agent 的舊裝置請設定原身分的帳號密碼。新註冊帳號不會帶入原本資料。

帳號限 3–32 個小寫英文、數字、_ 或 -，以英文字母開頭。密碼至少 12 個字元，建議使用英文字母、數字與符號。

忘記密碼時，請向管理員確認恢復方式，並保留仍可使用的已連線裝置。

進階：使用裝置連線碼或團隊邀請碼

僅供既有裝置配對與團隊邀請使用。自己的換機碼沿用同一身分；同仁邀請碼只加入指定團隊。

請重新確認使用權限

核准只開放雲端使用資格。團隊分享需另外邀請；其他人的私人資料不會開放。

雲端已連線

設定帳號密碼

為目前這份雲端資料設定登入方式。你的 Agent、Skill、Workflow 和團隊權限會保留；完成後可在網站直接登入。

帳號限 3–32 個小寫英文、數字、_ 或 -，以英文字母開頭。密碼至少 12 個字元，建議使用英文字母、數字與符號。

進階：產生一次性裝置換機碼

平常換裝置請直接使用帳號密碼登入。此連線碼只用於自己的裝置，不能用來分享給同仁。

帳號管理

帳號核准後仍需另外加入團隊。管理員帳號不能在此停用。
