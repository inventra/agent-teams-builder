## 輸入與輸出

以 input.schema.json 為唯一欄位清單，input.html 可填資料。付款條件、兌現日與無號碼收據須明確留空；不可從影片或前次請款擅自繼承。費用代號 2007 是已校準餐費用途的參考，並非所有請款預設。會計科目、對象姓名、總計由 ERP 產生；单號由 ERP 分配。

本流程只支援 PCMI10 iGP2.0 16.0.2.1、NTD 匯率 1、員工轉帳、一筆無號碼收據。非空收據號碼、發票與多筆明細另行校準。填齊欄位仍需正確的 ERP 版本及登入環境。
